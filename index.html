EXPORT
This allows you to export either MIDI or WAV files of recently played patterns, using a one-minute rolling buffer — everything actually played, randomness and all, not just the abstract pattern settings. Pick a saved pattern above (or leave it on current (live) to use whatever's already playing), then hit Save Selection to snapshot the last minute into a piano-roll timeline. Drag across it to select a range — it snaps to whole bars automatically. Use Preview to hear the selection before committing to a download, then export it as a MIDI file (for editing further in a DAW) or a rendered WAV audio clip. The buffer only fills while the transport is running, and loading a different pattern clears it, so let something play for a bit before opening Save Selection.
